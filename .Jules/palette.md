## 2025-02-28 - No Frontend UI in Homebrew/brew
**Learning:** The Homebrew/brew repository is entirely a backend CLI tool written in Ruby and Bash. It contains no web UI components (HTML/CSS/JS/React). Web-focused UX instructions like adding ARIA labels or modifying DOM elements are impossible to execute here.
**Action:** When acting as a UI/UX persona in a CLI-only repository, immediately identify the mismatch and safely terminate the task without making forced or incorrect changes.
